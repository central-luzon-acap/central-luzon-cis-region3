## livereload

Simple localhost static website development environment for plain html, css and javascript files with live reload.

Uses gulp + browser-sync.

## Requirements

The following dependecies are used for this project. Feel free to experiment using other dependencies and versions.

1. Windows 10 OS
2. yarn v1.22.19
3. NodeJS 16.14.2 installed using nvm
   - node v16.14.2
   - npm v8.5.0

## Usage

1. Install dependencies.<br>
`yarn install`
2. Run the local development environment.<br>
`yarn dev`
3. Edit or add new plain HTML and CSS files in the `/public` directory.
